# Audio Metadata Extractor

ابزاری برای استخراج متادیتای فنی، کیفیت، و سلامت از یک پوشه فایل صوتی. برای هر
فایل یک رکورد JSON کامل تولید می‌کند و در نهایت یک فایل CSV خلاصه از کل مجموعه
می‌سازد.

## قابلیت‌ها

- تشخیص فرمت و کدک واقعی هر فایل از روی محتوا (نه از روی پسوند نام فایل)
- استخراج مشخصات فنی: مدت، نرخ نمونه‌برداری، تعداد کانال، عمق بیت، بیت‌ریت
- محاسبه‌ی معیارهای کیفیت سیگنال: Peak، RMS، نسبت Clipping، نسبت تقریبی سکوت
- تشخیص فایل خراب یا غیرقابل‌خواندن بدون متوقف کردن پردازش بقیه‌ی فایل‌ها
- تشخیص فایل‌های تکراری بر اساس هش محتوا (SHA-256)، مستقل از نام فایل
- عدم تغییر فایل‌های ورودی در هیچ مرحله (دسترسی فقط‌خواندنی)

## پیش‌نیازها

- Python 3.9 یا بالاتر
- [`ffmpeg`](https://ffmpeg.org/) (شامل `ffprobe`) — باید در PATH سیستم در دسترس باشد
- کتابخانه‌ی `numpy`

```bash
pip install numpy
```

## استفاده

```bash
python3 audio_metadata_extractor.py --input ./input --output ./output
```

| آرگومان | توضیح | پیش‌فرض |
|---|---|---|
| `--input`, `-i` | پوشه‌ی حاوی فایل‌های صوتی (فقط خوانده می‌شود) | `./input` |
| `--output`, `-o` | پوشه‌ای که خروجی در آن نوشته می‌شود | `./output` |
| `--verbose`, `-v` | فعال‌سازی لاگ سطح Debug | خاموش |

## خروجی

```
output/
├── metadata/
│   ├── <audio_id_1>.json
│   ├── <audio_id_2>.json
│   └── ...
└── audio_inventory.csv
```

- **`metadata/<audio_id>.json`**: یک رکورد کامل برای هر فایل صوتی یکتا (ساختار
  دقیق در `metadata_schema.json` مستند شده است).
- **`audio_inventory.csv`**: خلاصه‌ی تمام فایل‌های پردازش‌شده در قالب یک جدول،
  شامل یک ردیف برای هر فایل ورودی (حتی فایل‌های تکراری یا خراب).

## فیلدهای هر رکورد

| فیلد | توضیح |
|---|---|
| `audio_id` | شناسه‌ی یکتا؛ ۱۶ کاراکتر اول هش SHA-256 فایل |
| `original_filename` | نام فایل در پوشه‌ی ورودی |
| `sha256` | هش کامل SHA-256 محتوای فایل |
| `format` / `codec` | فرمت ظرف و کدک صوتی، تشخیص‌داده‌شده از محتوای واقعی فایل |
| `duration_seconds`, `sample_rate`, `channels`, `bit_depth`, `bitrate` | مشخصات فنی صدا |
| `file_size_bytes` | اندازه‌ی فایل روی دیسک |
| `peak_level`, `rms_level`, `clipping_ratio`, `silence_ratio` | معیارهای کیفیت سیگنال، نرمال‌شده در بازه‌ی ۰ تا ۱ |
| `decode_status` | `"ok"` یا `"error"` |
| `error_message` | توضیح خطا در صورت خرابی فایل، در غیر این صورت `null` |
| `duplicate_of` | نام اولین فایلی که همین محتوا را داشته، در غیر این صورت `null` |
| `schema_version`, `processed_at` | نسخه‌ی ساختار داده و زمان تولید رکورد |

## نکات طراحی

- **تشخیص فرمت بر اساس محتوا انجام می‌شود، نه پسوند فایل.** کشف فایل‌ها در پوشه‌ی
  ورودی هم بر اساس پسوند فیلتر نمی‌شود؛ هر فایل مستقیماً به `ffprobe` سپرده
  می‌شود، چون فایل ممکن است بدون پسوند یا با پسوند نادرست باشد و همچنان صدای
  معتبری داشته باشد.
- **تشخیص تکراری بر پایه‌ی محتوا (هش) است، نه نام فایل**، چون دو فایل با نام‌های
  متفاوت می‌توانند محتوای یکسان داشته باشند.
- **پردازش هر فایل مستقل از بقیه است**؛ خرابی یک فایل باعث توقف کل فرایند
  نمی‌شود.
- **`bit_depth` برای کدک‌های فشرده مانند MP3 مقدار `null` دارد**، چون در این
  فرمت‌ها اصلاً مفهوم «بیت بر نمونه» وجود ندارد.
- **معیارهای کیفیت (به‌ویژه `silence_ratio`) تقریبی هستند**؛ بر پایه‌ی یک آستانه‌ی
  ثابت دامنه محاسبه می‌شوند، نه یک الگوریتم تشخیص سکوت پیشرفته.

## تست

رفتار ابزار در سه سناریو تأیید شده است:

- **فایل سالم و تکراری**: یک فایل و یک کپی دقیق از آن — کپی به‌درستی از طریق
  فیلد `duplicate_of` به فایل اصلی لینک می‌شود.
- **فایل خراب**: یک فایل با محتوای نامعتبر — رکورد آن `decode_status="error"`
  می‌گیرد و پردازش بقیه‌ی فایل‌ها ادامه پیدا می‌کند.
- **فایل بدون پسوند یا با پسوند نادرست**: فرمت واقعی همچنان از روی محتوا به
  درستی تشخیص داده می‌شود.

برای اجرای این سناریوها به‌صورت دستی:

```bash
ffmpeg -f lavfi -i "sine=frequency=440:duration=2" -ar 44100 -ac 1 input/sample.wav
cp input/sample.wav input/sample_copy.wav
head -c 3000 /dev/urandom > input/broken.wav
python3 audio_metadata_extractor.py --input input --output output
```

همچنین در تمام اجراها، عدم تغییر فایل‌های ورودی با مقایسه‌ی اندازه/هش فایل‌ها
پیش و پس از اجرا تأیید شده است.
