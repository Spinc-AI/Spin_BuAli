# تشخیص گفتار — خلاصهٔ معیارها

ارزیابی مدل‌های محلی تبدیل گفتار فارسی به متن (FLEURS fa_ir)<span class="added">، به‌همراه معیارهای بالینی برای ارزیابی گزارش‌های رادیولوژیِ دیکته‌شده</span>. دلیل استفاده از هر معیار.

<p class="legend"><span class="added">■ آبی = افزوده‌شده برای ارزیابی بالینی (رادیولوژی).</span> مشکی = مجموعهٔ اولیهٔ معیارهای STT.</p>

## دقت

| معیار | چرا استفاده می‌کنیم |
| ----- | ------------------- |
| **WER** | درصد کلمات غلط — معیار اصلی و استاندارد ASR. |
| **CER** | درصد نویسه‌های غلط — برای پسوندها و واژه‌بست‌های چسبیدهٔ فارسی منصفانه‌تر است. |
| **chrF** | هم‌پوشانی n-گرم نویسه‌ای — به تغییرات صرفی که WER کاملاً غلط می‌شمارد امتیاز نسبی می‌دهد. |
| **BERTScore (ParsBERT)** | تطابق *معنایی* در سطح توکن — به مترادف‌های درست که WER جریمه می‌کند امتیاز می‌دهد. |
| **شباهت معنایی** | تطابق معنای کل جمله با embedding — آیا پیام حفظ شده است. |

## پایایی (حیاتی برای کاربرد پزشکی)

| معیار | چرا استفاده می‌کنیم |
| ----- | ------------------- |
| **SER** | درصد کلیپ‌هایی که *هر* خطایی دارند — رونوشت چند وقت یک‌بار کامل است. |
| **WER P50 / P90 / P95** | کلیپ‌های معمول در برابر بدترین حالت؛ میانگین، پرت‌های بد را پنهان می‌کند. |
| **٪کامل / ٪فاجعه‌بار** | سهم کلیپ‌های بی‌نقص در برابر به‌شدت غلط. |
| **نرخ جایگزینی / درج / حذف** | *نوع* خطا؛ درج = کلمات توهمی (بالاترین ریسک پزشکی). |
| **نرخ خروجی خالی** | مدل چند وقت یک‌بار هیچ خروجی نمی‌دهد. |

## حالت‌های خطای خاص فارسی

| معیار | چرا استفاده می‌کنیم |
| ----- | ------------------- |
| **نسبت توهم** | طول خروجی به مرجع؛ بیشتر از ۱ یعنی ساختن کلمه. |
| **آلودگی خط** | درصد نویسه‌های غیرفارسی — نشت لاتین/انگلیسی را نشان می‌دهد. |
| **امتیاز تکرار** | n-گرم‌های تکراری — توهم حلقه‌ای Whisper روی سکوت را می‌گیرد. |
| **F1 نقطه‌گذاری** | مقایسهٔ منصفانهٔ مدل‌های نقطه‌گذار (Whisper) با مدل‌های متن خام (Wav2Vec2/MMS). |

<div class="added" markdown="1">

> **برای دیکتهٔ رادیولوژی معتبر نیست.** معیار «آلودگی خط» فرض می‌کند نویسهٔ لاتین یعنی نشت. در دیکتهٔ رادیولوژی، گوینده عمداً فارسی را با اصطلاحات انگلیسی مخلوط می‌کند (*hydronephrosis*، *UVJ*، *mm*)؛ بنابراین یک رونوشتِ کاملاً درست، «به‌شدت آلوده» امتیاز می‌گیرد. این معیار را مخصوص FLEURS بدانید، یا آن را با معیاری جایگزین کنید که بسنجد اصطلاحات انگلیسی *درست* نوشته شده‌اند یا نه — نه اینکه اصلاً وجود دارند یا نه.

## دقت بالینی (گزارش‌های رادیولوژیِ دیکته‌شده)

روی متن گزارش و در برابر مرجعِ تأییدشده توسط رادیولوژیست سنجیده می‌شود. ریسک بالینی در همین معیارهاست — یک گزارش می‌تواند WER خوبی داشته باشد و همچنان ناایمن باشد.

| معیار | چرا استفاده می‌کنیم |
| ----- | ------------------- |
| **نرخ خطای نفی** | وارونه‌شدن وجود/عدم وجود — «سنگ وجود ندارد» که «سنگ وجود دارد» رونویسی شود. تشخیص را کاملاً عوض می‌کند. |
| **نرخ خطای سمت** | جابه‌جایی راست/چپ (Right/Left) — یافته را به سمت اشتباه بدن منتقل می‌کند. |
| **نرخ خطای عدد** | مقدار اندازه‌گیریِ غلط — پرریسک‌ترین دستهٔ خطا؛ سنگ ۶ میلی‌متری که ۱ سانتی‌متر خوانده شود، تصمیم درمانی را تغییر می‌دهد. |
| **نرخ خطای واحد** | mm در برابر cm در برابر میلی‌متر و سانتی‌متر. کمیت فیزیکی مقایسه شود، نه رشتهٔ واحد — تا ۱۰ میلی‌متر و ۱ سانتی‌متر برابر شمرده شوند. |
| **دقت اصطلاح پزشکی (Precision)** | از اصطلاحات بالینیِ تولیدشده، چند تا واقعاً در مرجع پشتیبانی می‌شوند — اصطلاح‌سازیِ ساختگی را می‌گیرد. |
| **بازیابی اصطلاح پزشکی (Recall)** | از اصطلاحاتی که باید می‌بودند، چند تا باقی مانده‌اند — یافته‌های حذف‌شده را می‌گیرد. |
| **F1 اصطلاح پزشکی** | یک عدد ترکیبی برای کیفیت کلیِ اصطلاحات. |
| **نرخ حذف بحرانی** | محتوای مهمِ مرجع که در خروجی نیست. «بحرانی» باید صریح تعریف شود (اندازه‌گیری، یافتهٔ نفی‌دار، نشانگر سمت، یا اصطلاح علامت‌گذاری‌شده) وگرنه به «هر چیزِ جاافتاده» تقلیل می‌یابد. |
| **نرخ افزودهٔ بی‌پشتوانه** | محتوای خروجی که هیچ پشتوانه‌ای در مرجع ندارد — همان حالت جعل (مثلاً مدلی که سابقهٔ بیماریِ دیکته‌نشده می‌سازد). |
| **پرچم `requires_medical_review`** | برای هر گزارش، با بروز هر خطای بحرانی فعال می‌شود. در گردش‌کارِ پس‌ویرایش، این پرچم *بعد از* تأیید نهایی روشن می‌شود؛ پس یک محرک بازبینیِ ثانویه است، نه یک سد ایمنی. |

## حلقهٔ پس‌ویرایش (پایش زنده)

وقتی مرجع، نسخهٔ تصحیح‌شدهٔ خروجیِ خودمان توسط رادیولوژیست باشد، معنای اعداد فرق می‌کند: میزان تلاشِ ویرایش را می‌سنجند، نه درستی را.

| معیار | چرا استفاده می‌کنیم |
| ----- | ------------------- |
| **بار ویرایش (WER پس‌ویرایش)** | رادیولوژیست چقدر مجبور شده تغییر بدهد. یک سیگنال بارِ کاریِ تولید — آن را «دقت» نخوانید، چون مرجع از متن خودِ مدل مشتق شده است. |
| **٪پذیرش بدون تغییر** | سهم گزارش‌هایی که بدون هیچ ویرایشی تأیید شده‌اند. باید در کنار نشانه‌های تعامل دیده شود: گزارشی که فقط مهر تأیید خورده، از گزارش درست قابل تفکیک نیست. |
| **نرخ بازگشت تصحیح** | چه سهمی از خروجی‌ها اصلاً تصحیح‌شده برمی‌گردند. بازگشت کم یا سوگیرانه یعنی نمونهٔ ارزیابی به‌سمت گزارش‌های آسان‌تر منحرف شده است. |
